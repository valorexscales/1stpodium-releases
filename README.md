# 1st Podium — lançamentos do 1st App

Este repositório guarda **apenas** os instaladores oficiais do 1st App e o
arquivo de versão que o botão **"Buscar atualizações"** consulta.

- `app/latest.json` — versão atual, novidades, link e SHA-256 do instalador.
- Instaladores: aba **Releases** (`app-vX.Y.Z`).

Site: https://1stpodium.vercel.app/ · Discord: https://discord.gg/PUbAF8kpuU
